# cui-mobile (experimental)

Skill for CUI v1.5's **experimental Android and iOS backends**: touch input
API, the Android Gradle/sideload path, and the iOS (macOS-only) build notes.
Lives on the `mobile` branch until it proves itself — not merged to `main`.

Install from this branch:

```sh
npx skills add ChiakoRh/cui-skills#mobile
```

(or `npx skills add ChiakoRh/cui-skills#mobile --list` to only list what it
would install). Everything else in this repo is the four stable skills from
`main`.

The skill is written from the v1.5 docs, not from a real device build yet —
its "Build log" section fills in after the first `sideload-apk.sh` run.
